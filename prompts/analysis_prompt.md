# 股票趋势分析 Prompt 模板

## 使用方法

将模板中的 `{基本面上下文}` 和 `{行情数据}` 替换为实际数据。

```bash
# 生成完整上下文（基本面+行情+prompt）
python3 -m stock_cli context 000001.SZ --days 120
```

---

## 数据来源

### {基本面上下文}

来自 `fundamental_info` 表，3个维度：

| 维度 | 字段 | 来源论文 | 预测 |
|---|---|---|---|
| 质押状态 | `pledge_status` | 谢德仁 2016《管理世界》 | 质押期维稳 -> 解押后暴跌 |
| 盈余管理 | `earnings_management_level` | 潘越 2011 + 辛清泉 2014 | 不透明度 -> 暴跌风险 |
| 四大审计 | `big4_audit` | 辛清泉 2014 | 非四大 -> 波动性更高 |

### {行情数据}

来自 `stock_info` 表，21列完整数据：

- OHLCV: open/high/low/close/vol/amount
- 涨跌: pre_close/change/pct_chg
- 筹码分布: cost_5pct/cost_15pct/cost_50pct/cost_85pct/cost_95pct
- 其他: weight_avg/winner_rate/his_low/his_high/cost_concentration_90pct

## 风险预警规则

### 1. 股权质押信号（谢德仁 2016）
- **质押期**: 崩盘风险被人为压低（控股股东通过盈余操纵维稳股价）
- **解押后**: 崩盘风险显著上升（维稳动力消失，积累的风险释放）
- **机制**: 质押 -> 盈余管理 -> 信息透明度 -> 股价维稳 -> 解押 -> 风险释放
- **预警阈值**: 质押比例>50%为高质押，解押事件是最强预警信号

### 2. 盈余管理信号（潘越 2011 + 辛清泉 2014）
- **不透明度 -> 暴跌风险**: 潘越论文系数1.1327，1%显著
- **透明度 -> 波动性**: 透明度从25分位升至75分位方差下降约均值水平
- **计算方法**: 修正Jones模型，残差=操控性应计利润，不透明度=前3年|残差|之和

### 3. 四大审计信号（辛清泉 2014）
- **四大审计 -> 波动性更低**: 信息质量保障更强
- **非四大 -> 信息风险更高**: 审计保障弱，盈余操纵空间更大
- **与盈余管理的关系**: 四大审计的公司，盈余管理程度通常更低

### 维度间的协同效应
- **质押 + 高盈余管理**: 质押公司盈余管理程度更高
- **非四大 + 高盈余管理**: 无审计约束的盈余操纵，信息不透明更严重
- **刚解押 + 高盈余管理**: 最危险组合——质押维稳期积累的盈余操纵在解押后释放
